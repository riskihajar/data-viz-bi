Catatan Metodologis: Dashboard ini menggunakan model sebagai scoring engine dan knowledge-based risk layer sebagai penjelas risiko. Metrik teknis model tidak ditampilkan di sini karena dashboard ditujukan untuk keputusan monitoring akademik. Kode module (AAA–GGG) merupakan anonimisasi dari penyedia dataset OULAD dan tidak merepresentasikan nama mata kuliah sebenarnya.
